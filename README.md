
# Learn Through Project

A collection of practical software development projects
built through hands-on learning.

Projects explore Python, web development, Linux,
automation, and application development.

## Projects

### 1. wPlanner — Weekly Scheduling Application

A personal weekly planner for organizing activities,
managing time slots, and resolving scheduling conflicts.

[View wPlanner](./wPlanner/)

### 2. dboard — Ubuntu Desktop Productivity Widget

A minimalist, Python-powered productivity dashboard
integrated directly into the Ubuntu GNOME desktop.

**Features**
- Daily tasks and deadlines
- Project progress tracking
- Weekly schedules and notes
- Editable desktop interface
- Compact mode and custom themes
- Persistent local storage

**Technologies:** Python, JavaScript, GNOME Shell, CSS

[View dboard](./dboard/)
