
# dboard Changelog

## v1.0.0 — Initial Public Release

### Features
- GNOME desktop productivity widget
- Python-powered data management
- Add, edit, complete and delete tasks
- Deadline tracking and countdowns
- Project progress visualization
- Weekly schedule management
- Editable notes
- Compact and Full modes
- Collapsible sections
- Light and dark themes
- Transparency and positioning controls
- Persistent layout and settings

### Improvements
- Minimalist macOS-inspired interface
- GNOME symbolic icons
- Improved layout spacing
- Desktop Icons NG compatibility workaround
- Portable installation
- Local data migration and backup support

### Compatibility
- Ubuntu 26.04
- GNOME Shell 50
- Wayland

### Known Limitations
- GNOME Shell internals may change in future versions
- No cloud synchronization
- No desktop deadline notifications
